1. Panoramica del Progetto
1.1 Obiettivo
Sviluppare un gestionale web completo per Nagma Tattoo Studio, pensato per ottimizzare la gestione operativa quotidiana: prenotazioni, clienti, collaboratori, finanze, vendita prodotti e statistiche ISTAT del negozio. Il sistema deve essere moderno, reattivo e integrabile con l’ecosistema Microsoft (Outlook Calendar).

4. Integrazione Microsoft Outlook
4.1 Autenticazione
Usa NextAuth.js con provider Azure AD / Microsoft
Scope richiesti: Calendars.ReadWrite, offline_access
Token salvato in sessione (o DB) per chiamate server-side
4.2 Flusso di Sincronizzazione
1. Utente crea/modifica prenotazione nel gestionale2. Backend → chiama Microsoft Graph API   POST https://graph.microsoft.com/v1.0/me/events   {     subject: "Tattoo - {Cliente}",     start: { dateTime: "...", timeZone: "Europe/Rome" },     end: { dateTime: "...", timeZone: "Europe/Rome" },     body: { content: "Artista: {Artista}\nNote: {Note}" }   }3. Salva outlookEventId nella prenotazione4. Per aggiornamenti → PATCH /me/events/{outlookEventId}5. Per cancellazioni → DELETE /me/events/{outlookEventId}
4.3 Gestione Errori
Se la sincronizzazione Outlook fallisce → la prenotazione viene comunque salvata nel DB
Errore mostrato come warning non bloccante
Retry automatico configurabile

9. Note Tecniche Aggiuntive
Form Dinamico in Base64
Il titolare potrà configurare liberamente la struttura dei form di prenotazione senza modificare il codice. La struttura viene: 1. Definita visualmente nell’area Impostazioni 2. Serializzata in JSON → codificata in Base64 3. Salvata nel DB come FormTemplate.schemaB64 4. Decodificata a runtime nel modal → renderizzata dinamicamente
Questo permette di aggiungere campi custom (tipo di tattoo, dimensione, posizione sul corpo, firme consenso, ecc.) senza deploy.
WhatsApp Deep Link
const buildWhatsAppUrl = (phone: string, template: string, vars: Record<string, string>) => {  const message = template.replace(/\{\{(\w+)\}\}/g, (_, key) => vars[key] || '')  const encoded = encodeURIComponent(message)  const cleanPhone = phone.replace(/\D/g, '')  return `https://wa.me/39${cleanPhone}?text=${encoded}`}
